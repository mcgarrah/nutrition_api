Nutrition API

A unified food-intelligence service: one lookup that merges USDA FoodData Central, Open Food Facts, and the GS1 Global Product Classification.

Look up by barcode /lookup
Have a GTIN or UPC? Scan or type it to see the merged product card, per-source provenance, and latency.
🔎
Search by name /search
Don't have a barcode? Search by product name, pick a result, and see its Nutrition Facts label.
Explore the data
Data explorer /data
Four tabs, one page: Data Browser (schema, rows, column coverage), Data Quality (coverage, value distributions, cross-source agreement), GPC Taxonomy, and GPC Mapping Viewer.
Operate
Status /status
Live dashboard — proxy, backend, cached copies, and external APIs at a glance.
Swagger UI /docs
Interactive API reference — call any endpoint from the browser.
ReDoc /redoc
Clean, reference-style documentation of the same OpenAPI schema.
